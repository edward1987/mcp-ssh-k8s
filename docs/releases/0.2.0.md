## What's new

- **A guided Windows installer**, available in English and Romanian, with Start menu and optional desktop shortcuts.
- **“Start automatically with Windows as a service”**: choose during setup. The service runs as `LocalService`, starts with a delay and restarts after a failure.
- **Keep your existing database**: select the folder containing `vault.json`. Hosts, SSH keys, Kubernetes configs, MCP tokens, settings and audit history remain available with the same master password.
- **A backup before installation**: existing vault and audit records are copied into the selected data folder's `backups` directory.
- **A visible data location** in the web interface: **Setări → Date locale**.
- **Repeatable release builds**, pinned runtime downloads, SHA-256 verification and a GitHub Actions build workflow.
- Updated transitive `body-parser` and `fast-uri` dependencies to resolve the advisories reported by npm audit at release time.

## Install in a few steps

1. Download and run the `.exe` above.
2. Select your data folder. For a new installation, keep the proposed ProgramData folder.
3. Choose whether to start automatically as a Windows service.
4. Open **MCP SSH K8s** from Start or visit **http://127.0.0.1:7777**.
5. Create a master password for a new vault, or unlock your existing vault with its current password.

### Already running from source?

Stop the old instance first. In setup, choose the **existing `data` folder containing `vault.json`**. Setup reuses it in place; it does not copy it into Program Files. Keep that folder after installation. You can also copy it to a permanent location while the app is stopped and select the copy.

**For the original local checkout:** select `D:\apps\mcp-ssh\data` if that is where your vault lives. The installer itself does not contain this path or any user's database.

## After a restart

The Windows service starts the application automatically. **The vault stays locked until you enter your master password in the browser.** Automatic tunnel startup, if enabled, happens after unlocking. The installer never stores the master password.

The admin interface and installed MCP endpoint listen on loopback (`127.0.0.1`). Existing MCP tokens stay valid when reusing the same vault. Uninstalling preserves the selected data folder, backups and logs.

## Optional tools and notes

- **Kubernetes:** install `kubectl` separately in the system PATH for service mode. External kubeconfig authentication plugins need their own setup under the runtime account.
- **Local Termius import:** use manual mode under your Windows user so the app can access your Termius profile and Credential Manager. Already imported credentials work in service mode.
- **Windows SmartScreen:** this installer is unsigned. Its publisher may appear as unknown; compare its SHA-256 with `SHA256SUMS.txt`.
- Logs are stored under `<your-data-folder>\logs`. Stop the manual instance before upgrading or uninstalling.
