`Romanian.isl` is the user-contributed Inno Setup Romanian translation by
Alexandru Bogdan Munteanu. The original translator notice is preserved.

Source: https://github.com/jrsoftware/issrc/blob/5bcadfcd05e9857a47a6880a2ac0694c9ab60122/Files/Languages/Unofficial/Romanian.isl

Upstream license: https://github.com/jrsoftware/issrc/blob/5bcadfcd05e9857a47a6880a2ac0694c9ab60122/license.txt

The translation uses its original Windows-1250 encoding. It is vendored because
Inno Setup does not include unofficial translations in its standard install.
Newer optional download/verification messages fall back to English.
